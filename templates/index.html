CyberLens reads a security log or dataset, flags the entries that look like attack activity, and writes it up as a report you can hand to someone else.

It reads files you give it. It never touches a live network, and it never runs anything it finds inside a file.

What it recognises

Six attack categories, learned from labelled examples. Anything outside these is out of scope, and the tool says so.

  • Brute ForceBursts of failed logins against accounts or services.
  • Port ScanOne address probing many ports to map what is open.
  • Malware ActivityEncoded payloads, beaconing, dropped executables, ransomware noise.
  • SQL InjectionDatabase manipulation attempts inside web requests.
  • Privilege EscalationSudo abuse, sensitive-file access, permission changes.
  • DoS IndicatorsFloods and request patterns aimed at exhausting capacity.
